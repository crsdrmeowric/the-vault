# the-vault

Welcome to the official repository for The Vault. This project was developed for our ITPE 1 subject under Mr. Narte. We are a team of 5 freshmen students tasked with building a clean, responsive static website from scratch. 

Since our group shares an interest in gaming, we decided to design a mock-up of a digital gaming storefront, drawing inspiration from platforms like Steam.
